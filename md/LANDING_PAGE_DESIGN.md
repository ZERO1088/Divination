## 2. 每个 Section 的作用

| Section | 核心作用 | 如果缺失会怎样 |
|---------|---------|---------------|
| Hero | 建立空间感、品牌气质、给出"我是谁"的答案 | 用户不知道这是什么地方 |
| Ritual Gateway | 给出两个明确的行动入口，降低选择焦虑 | 用户不知道该做什么 |
| Ritual Flow | 解释"占卜不需要害怕"——3 步流程消除神秘化 | 新用户可能不敢点 |
| AI Companion | 传递核心价值——这不是算命工具，是情绪陪伴 | 被误解为玄学 App |
| Emotional Anchor | 制造情绪共鸣——让用户"被看见"的感觉达到峰值 | 产品缺少情感温度 |
| Trust & Privacy | 消除最后的顾虑——数据安全 | 用户不敢输入真实问题 |
| Final CTA | 给犹豫到最后的用户一个推动 | 流失在最后一刻 |
| Footer | 完成页面，不遗留未完成感 | 页面像"烂尾" |

## 4. 每个 Section 的动效描述

| Section | 动效 | 触发时机 | 时长 |
|---------|------|---------|------|
| Hero | "玄机" 从 opacity 0 + y:20 → opacity 1 + y:0 | 页面加载后 200ms | 600ms |
| Hero | Slogan 延迟 300ms 后 fade-in | 品牌名动画结束后 | 500ms |
| Hero | CTA 按钮呼吸发光（循环） | 页面加载完成后持续 | 3000ms/cycle |
| Hero | 向下箭头极慢 bounce | 持续循环 | 3000ms/cycle |
| Ritual Gateway | 两张卡片：左侧先 fade-in + x:-20→0，右侧延迟 150ms 同效 | 滚动到 Section 可见时 | 500ms/张 |
| Ritual Gateway | 卡片 hover：translateY(-4px) + 金色边框发光 | hover 触发 | 200ms |
| Ritual Flow | 三步卡片 stagger fade-in（每步延迟 100ms） | 滚动到 Section 可见时 | 400ms/张 |
| Ritual Flow | 箭头从左到右渐显 | 三步卡片动画中途 | 300ms |
| AI Companion | Feature Pills stagger fade-in（每个延迟 80ms） | 滚动到 Section 可见时 | 300ms/个 |
| Emotional Anchor | 文字极慢 fade-in（1200ms） | 滚动到 Section 可见时 | 1200ms |
| Trust & Privacy | 图标 scale 0.8→1 + fade-in | 滚动到 Section 可见时 | 600ms |
| Final CTA | 按钮呼吸发光（比 Hero CTA 更强） | 滚动到 Section 可见时开始 | 3000ms/cycle |
| 全局 | Section 之间的过渡：下一个 Section 的元素在滚动到视口 60% 位置时触发入场动画 | Intersection Observer | — |

**动效的"克制"原则**：
- 不重复触发——每个 Section 的入场动画只播放一次
- 不叠加——同一时刻最多只有一个 Section 在执行入场动画
- 不抢夺——动画的最高光时刻在 Hero 和 Emotional Anchor

## 5. 每个 Section 的空间关系

### 5.1 虚空分配

```
Section               │ 虚空占比    │ 内容占比    │ 留白逻辑
──────────────────────┼────────────┼────────────┼────────────────────
Hero                  │ 75%        │ 25%        │ 品牌名被大量虚空包裹
Ritual Gateway        │ 50%        │ 50%        │ 两张卡片之间有呼吸间隙
Ritual Flow           │ 40%        │ 60%        │ 三步流程需要一定的信息密度
AI Companion          │ 55%        │ 45%        │ 标题上下各留大量空白
Emotional Anchor      │ 85%        │ 15%        │ 极致虚空——只有一句话
Trust & Privacy       │ 60%        │ 40%        │ 信任信息不应拥挤
Final CTA             │ 80%        │ 20%        │ 只有一个按钮
Footer                │ 70%        │ 30%        │ 一行字，其余虚空
```

### 5.2 Section 间距

```
Hero → Ritual Gateway:      mt-20 (80px)
Ritual Gateway → Ritual Flow: mt-24 (96px)
Ritual Flow → AI Companion:   mt-24
AI Companion → Emotional Anchor: mt-32 (128px) ← 最大的过渡留白
Emotional Anchor → Trust:    mt-20
Trust → Final CTA:           mt-20
Final CTA → Footer:          mt-16 (64px)
```

间距的逻辑：在 Emotional Anchor 前后留出最大的空白——因为那是情绪的最高点，需要呼吸。

### 5.3 聚焦与弱化

| Section | 聚焦（用户应该看什么） | 弱化（用户不需要看什么） |
|---------|---------------------|------------------------|
| Hero | "玄机" + CTA | 星云背景（感知但不阅读） |
| Ritual Gateway | 两张入口卡片 | Section 标题（如有） |
| Ritual Flow | 三个步骤 | 连接箭头 |
| AI Companion | 标题 + Feature Pills | 描述段落（辅助阅读） |
| Emotional Anchor | 引用文字 | 无其他元素 |
| Trust & Privacy | 标题 | 描述段落 |
| Final CTA | 按钮 | 底部小字 |
| Footer | — | 全部信息都弱化 |

## 6. 页面视觉节奏

### 6.1 用户滚动时的情绪曲线

```
Section          │ 视觉刺激   │ 情绪状态
─────────────────┼───────────┼──────────────────
Hero             │ 中         │ 安静、被包裹、好奇
  ↓ 滚动
Ritual Gateway   │ 中偏低     │ 探索、选择
  ↓ 滚动
Ritual Flow      │ 低         │ 理性认知（"原来这么简单"）
  ↓ 滚动
AI Companion     │ 低         │ 初步信任建立
  ↓ 滚动
  （最大的留白过渡——128px 虚空）
  ↓
Emotional Anchor │ 极高       │ ⚡ 情绪峰值——"它真的懂我"
  ↓ 滚动
Trust & Privacy  │ 低         │ 理性确认（安全）
  ↓ 滚动
Final CTA        │ 中高       │ 行动冲动
  ↓ 滚动
Footer           │ 极低       │ 结束
```

### 6.2 节奏设计的关键

- Emotional Anchor 之前连续两个低刺激 Section——用户处于"理性浏览"模式
- 紧接着 128px 的巨大留白过渡——让用户"进入情绪空间"
- Emotional Anchor 一句话制造情绪峰值——之前所有的理性铺垫都为了此刻
- 峰值之后用 Trust 冷却——给理性一个"确认安全"的机会
- Final CTA 再次唤起行动冲动

## 7. 页面中哪些元素必须成为"视觉主角"

### 7.1 三个绝对主角

```
优先级     │ 元素              │ 所在 Section    │ 原因
──────────┼──────────────────┼────────────────┼──────────────
第 1 主角  │ "玄机" 品牌名      │ Hero           │ 这是品牌的根
第 2 主角  │ Emotional Anchor │ Emotional      │ 这是情绪的核
          │ 引用文字          │ Anchor         │
第 3 主角  │ CTA 按钮          │ Hero + Final   │ 这是行动的出口
          │                   │ CTA            │
```

### 7.2 永远不能成为主角的元素

- 导航栏（它是门框，不是房间里的家具）
- Ritual Flow 的三步卡片（它是说明书，不是海报）
- Feature Pills（它们是标签，不是标题）
- Footer（它是收据，不是内容）
- 任何图标/装饰元素（它们是辅助，不是焦点）

### 7.3 主角设计的共同原则

- 主角 = 金色（amber-200）+ serif 字体 + 最大字号 + 最多周围留白
- 一个 Section 只有一个主角
- 主角之间不竞争——它们出现在页面的不同深度，用户一次只看到一个

## 8. 高级感设计原则

### 8.1 Landing Page 专项原则

1. **一个页面，一个故事**
   - 用户 scrolling 的过程 = 阅读一个完整情绪故事的过程
   - 每个 Section 是故事的章节，不是功能的罗列

2. **虚空是最奢侈的元素**
   - 敢于让一个 Section 80% 是空的
   - 敢于在 Emotional Anchor 前后各留 128px 空白
   - Demo 思维：填满每一寸屏幕。商业思维：用虚空说话

3. **不让用户做选择，让用户做决定**
   - 整个页面只有两类行动：进入六爻 / 进入塔罗 / 开始占卜
   - 没有"了解更多"、没有"查看详情"、没有"探索更多"
   - 选择 = 认知负荷。决定 = 情绪冲动。我们要后者

4. **信息渐进而非倾泻**
   - 品牌 → 入口 → 流程 → AI 陪伴 → 情绪峰值 → 信任 → CTA
   - 顺序不可颠倒

5. **情绪峰值只出现一次**
   - 整个页面只有一个 Emotional Anchor
   - 在此之前是铺垫，在此之后是收束

6. **信任信息放在情绪峰值之后**
   - 用户在被 Emotional Anchor 击中后，会产生"我愿意试试"
   - 紧接着的 Trust 解决最后一个理性顾虑

7. **CTA 出现两次，但它们是同一个行动的延伸**
   - Hero CTA = "我想了解"（探索式）
   - Final CTA = "我准备好了"（决定式）

8. **不允许信息同时出现**
   - 品牌名先来（600ms）→ Slogan 再来（+300ms）→ CTA 再来（+200ms）
   - 用户接收信息的顺序被严格控制

9. **不允许卡片堆叠**
   - 整个页面只有 Ritual Gateway 有两张卡片（并排）
   - 任何地方不出现 >2 张卡片的堆叠

10. **所有发光必须来自金色**
    - 没有白色 glow（冷）、没有蓝色 glow（科技）、没有紫色 glow（廉价）
    - 金色 glow 的用途：CTA 呼吸、卡片 hover、Emotional Anchor 文字微光

### 8.2 具体禁止

| 禁止 | 为什么 |
|------|--------|
| Hero 使用背景图片 | 加载闪烁 + 破坏纯粹的虚空感 |
| 多列布局（除 Gateway 的 2 列） | 信息密度过高 |
| 卡片超过 2 张并排 | 选择焦虑 |
| 滚动触发的视差效果 | 眩晕 + 性能问题 |
| 自动播放视频/音频 | 侵扰 |
| 任何形式的倒计时/紧迫感 | 占卜不应制造焦虑 |
| "限时免费"等促销文案 | 破坏信任 |
| 小于 16px 的留白 | 拥挤感 |

## 9. 移动端设计逻辑

### 9.1 布局变化

```
Section            │ 桌面端                  │ 移动端
───────────────────┼────────────────────────┼────────────────────
Hero               │ 100vh 垂直居中          │ 100vh 垂直居中，字号缩小一级
Ritual Gateway     │ 两列并排                │ 单列上下堆叠，卡片全宽 - 32px
Ritual Flow        │ 三列水平 + 箭头          │ 单列垂直 + 箭头旋转 90°
AI Companion       │ Pills 水平排列           │ Pills 换行（2+1 或 1+1+1）
Emotional Anchor   │ 60vh                    │ 40vh（文字改小但虚空感不变）
Trust & Privacy    │ 不变                    │ 不变
Final CTA          │ 50vh                    │ 40vh
Footer             │ 不变                    │ 不变
```

### 9.2 移动端特殊处理

- Hero 的 "玄机" 从 `text-5xl` 缩小到 `text-4xl`
- Slogan 文字换行由 `text-balance` 控制
- Ritual Gateway 卡片触摸目标最小 44px 高度
- Emotional Anchor 保留 40vh 高度——虚空感不能因屏幕变小而消失
- 所有 Section 的内边距从 `px-8` 缩小到 `px-4`（但上下间距不变）
- Section 之间的间距在移动端缩小 20%
- 所有 hover 效果在移动端转为 `active` 效果

### 9.3 移动端的"掌中空间"

- 移动端距离眼睛更近——字号的缩小幅度小于屏幕的缩小幅度
- 虚空占比略降（从 75%→60%）——但"虚空感"通过减少同时可见的元素数量来维持

## 10. 为什么这个页面比普通 Demo 更高级

### 10.1 Demo 的特征 vs 商业级的特征

```
维度           │ Demo（学生作品）               │ 商业级（玄机）
───────────────┼──────────────────────────────┼──────────────────────────
信息密度       │ 每个 Section 塞满内容           │ 80% 虚空 + 20% 内容
              │ "我怕用户不知道有什么功能"        │ "用户不需要一次性知道所有"
              │                                │
动效           │ 每个元素都动、弹跳、旋转         │ 只有 3 个主角有入场动效
              │ "动效多 = 厉害"                 │ "动效是标点符号，不是正文"
              │                                │
色彩           │ 五彩斑斓、渐变按钮、发光标题     │ 一个强调色（amber）+ 五级灰阶
              │ "颜色多 = 好看"                 │ "光不是颜色，是深度"
              │                                │
卡片           │ 3-6 张卡片堆叠、阴影厚重         │ 最多 2 张卡片并排、光晕替代投影
              │ "卡片多 = 内容丰富"             │ "少即是信任"
              │                                │
文案           │ "欢迎来到玄机！快速开始占卜吧！"  │ "在不确定中，寻一个安放之处"
              │ "功能罗列式"                    │ "情绪共鸣式"
              │                                │
CTA            │ 多处 CTA："了解更多""立即体验"   │ 全局只有 2 个 CTA，召唤同一个行动
              │ "开始占卜""探索功能"            │ "让用户做决定，不做选择"
              │                                │
节奏           │ 匀速、平铺、无高低起伏           │ 铺垫 → 情绪峰值 → 回落 → 终曲
              │ "每个 Section 一样重要"         │ "只有一个情绪顶点"
              │                                │
留白           │ 紧张——不敢留白                  │ 慷慨——虚空是奢侈的
              │ "空白 = 浪费空间"               │ "空白 = 尊重用户注意力"
              │                                │
信任           │ 没有隐私说明                   │ 情绪峰值后精准放置信任信息
              │ 或大段法律术语                  │ 用最直白的中文承诺
              │                                │
结束感         │ 页面突然中断                   │ Footer 安静收束
              │ 或 Footer 堆满链接              │ 一行字，页面优雅结束
```

### 10.2 一句话总结

> Demo 试图用"多"来证明价值。玄机用"少"来传递信任。

一个页面不需要 10 个 Section、8 个功能点、5 个 CTA 来证明自己是"产品"。相反——一个敢于只放一句话、只留一个按钮、让 128px 虚空沉默存在的页面，才是真正完成了从"学生作业"到"商业产品"的跨越。
